## 2. Distinction: Programming Languages vs. Frameworks & External Services

In compliance with copyright registration guidelines, the following distinction is drawn between original author-written programming code and third-party frameworks or external APIs utilized by the software:

### 2.1 Original Author-Written Software (Subject of Copyright)
- **Original JavaScript/JSX Software Source Code**: All original algorithms, assessment evaluation engines (`lib/assessment-engine.js`), statutory requirement registries (`lib/requirement-registry.js`), synchronous inspection runners (`lib/assessment-runner.js`), SSRF and URL validation controllers (`lib/security.js`), sensitive data redactors (`lib/evidence-redactor.js`), autonomous safety controllers (`lib/safety-controller.js`), custom UI components (`components/*.jsx`), and dynamic Next.js App Router endpoints (`app/`).
- **Original Data Models**: 16 Mongoose document schemas defined in `models/` modeling organizations, approved targets, assessment profiles, statutory findings, test runs, and audit logs.
- **Original Test Suites & Verification Scripts**: Statutory legal framework test suites (`scripts/test-dpdp-2026-board-requirements.mjs`) and direct execution verification harnesses.

- **Node.js**: Underlying JavaScript server runtime.
- **Tailwind CSS**: Utility-first CSS layout engine (MIT License).
- **Mongoose**: MongoDB object modeling library (MIT License).
- **Playwright / @sparticuz/chromium**: Browser automation library and serverless Chromium binary (Apache 2.0 / MIT).

### 2.3 External AI & Cloud Services (Third-Party Cloud APIs)
